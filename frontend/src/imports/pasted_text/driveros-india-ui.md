Design a complete responsive web application UI for "DriverOS India".

====================================================
PRODUCT VISION
====================================================

DriverOS India is a Digital Operating System for Indian truck drivers.

It transforms the unorganized transport ecosystem into a fully digital system where drivers can manage:

- Documents (License, RC, Insurance, PUC, Permit)
- Compliance & legal status
- Vehicle records & maintenance
- Trip management
- Government policy updates
- Emergency support
- Health information

This is a full SaaS platform, NOT just a login or mobile app.

====================================================
TARGET USERS
====================================================

Primary:
- Indian Truck Drivers

Secondary:
- Fleet owners
- Transport companies
- Logistics managers

Context:
- Long highway travel
- Low digital literacy users
- Mobile-first usage with desktop support for fleet owners

====================================================
GLOBAL UI REQUIREMENTS
====================================================

- Fully responsive web app (mobile + desktop)
- SaaS dashboard style
- Clean, professional, government-tech hybrid design
- Large readable UI elements
- High contrast for road usage
- Simple navigation (max 5 main sections)
- Multilingual support (India-first)
- Fast, low-click UX
